# Day 6 – Practice

Light practice, one short file per concept. Each file needs only the structured lesson
named at its top, has **two TODOs**, and takes about five minutes.

| File | After lesson | You write |
|------|--------------|-----------|
| `practice_01_class_and_object.py` | 01–02 | one attribute and one method |
| `practice_02_encapsulation.py` | 03 | a checked `withdraw` and a `get_balance` |
| `practice_03_inheritance.py` | 04 | a child `__init__` with `super()` and one override |
| `practice_04_polymorphism.py` | 05 | the same method in two more classes |
| `practice_05_abstraction.py` | 06 | one class that keeps a contract |

```bash
cd Day6_Practice
python practice_01_class_and_object.py
```

A fresh file prints `NOT YET` on the lines that wait for your code. Finish a TODO, run the
file again, and watch the line turn to `PASS`. The text in brackets after `NOT YET` is the
error Python raised, which tells you what is still missing.

`checker.py` is a small module that the practice files import. Keep it in this folder.
