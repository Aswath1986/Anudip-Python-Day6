## The one thread through the day

| Day | We learned to reuse | With |
|---|---|---|
| Day 5 | a rule | a function |
| Day 5 | a file of rules | a module, a library |
| Day 6 | data together with its rules | a class |

Every Day 6 topic answers one problem:

| Concept | The problem it solves |
|---|---|
| Class and object | Data in one place, its rules in another, nothing tying them together |
| Encapsulation | Any line of code can put a wrong value into the data |
| Inheritance | Two classes repeat the same code |
| Polymorphism | An `if / elif` chain that must be edited for every new type |
| Abstraction | Nothing forces every class of a family to provide the same methods |

Needs only Python 3, nothing to install.

```bash
cd Day6_Structured
python 01_class_and_object.py
```
